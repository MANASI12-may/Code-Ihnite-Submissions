# Competition Submissions

Welcome!

Submit your competition project using the following steps:

1. Fork this repository.
2. Create a folder named after your GitHub username.
3. Upload your project files into that folder.
4. Commit your changes.
5. Create a Pull Request to this repository.

Your Pull Request title should be:

`Submission - Your GitHub Username`

Please ensure your submission includes:

* Your project files
* A README explaining your project
* Any required documentation

Thank you!
